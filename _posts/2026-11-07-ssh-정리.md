## SSH란?

SSH는 다른 컴퓨터에 **암호화해서 원격 접속**하는 도구다.
nc가 "날것 연결"이라면, SSH는 암호화 + 로그인이 붙은 정식 원격 접속이다.

## 기본 사용법

```bash
ssh 사용자이름@주소        # 기본 22번 포트로 접속
ssh -p 2222 user@주소     # 포트 지정
ssh -i key.pem user@주소  # 개인키 지정
```

## SSH는 프로그램이 두 개다

| 역할 | 프로그램 | 하는 일 |
|------|----------|---------|
| 서버 | `sshd` | 포트를 열고 기다림 (22번) |
| 클라이언트 | `ssh` | 그 포트로 접속하러 감 |

> 서버에 `sshd`가 켜져 있어야만 클라이언트가 접속할 수 있다.
{: .prompt-tip }

이건 소켓의 `listen/accept`(서버)와 `connect`(클라이언트) 구조에
암호화와 로그인만 얹은 것이다.
